# 🚀 FundSpark – Crowdfunding Platform (Frontend)

## 📌 Project Title
FundSpark – A Crowdfunding Web Application

---

## 📖 Project Description

FundSpark is a modern crowdfunding web platform that allows users to create fundraising projects, set funding goals, define milestones, and receive contributions from supporters.

Users can register, log in, create projects, browse by categories, and manage their creator dashboard. The frontend is built using React and connected directly to Supabase for database and authentication services.

---

## ✨ Features

- 🔐 User Authentication (Login / Register)
- 📝 Create New Project
- 🎯 Set Funding Goal & Deadline
- 🏆 Add Milestones & Rewards
- 📊 Creator Dashboard
- 📂 Browse Projects by Category
- 📄 Project Details Page
- 💳 Contribution Flow
- 🌐 Responsive UI
- 🚀 Deployed on Netlify

---

## 🛠 Tech Stack Used

- React.js
- React Router DOM
- JavaScript (ES6+)
- node.js
- express.js
- Fetch API
- CSS / Tailwind CSS
- Supabase (Database & Auth)
- Netlify (Deployment)
